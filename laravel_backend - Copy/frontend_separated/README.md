# Frontend Files - Separated from Laravel Project

This directory contains all the frontend assets and files extracted from the Laravel project.

## Directory Structure

### `/assets/` - Images and Media Files
- Contains 32 image files including:
  - Product images (spices, handicrafts, ayurvedic products)
  - Category images (Ceylon spices, batik wear, wooden handicrafts)
  - UI elements (dashboard wallpaper, slide images)

### `/css/` - Stylesheets
- `app.css` - Main application styles
- `cart.css` - Shopping cart styles
- `catagary.css` - Category page styles
- `conect_us.css` - Contact page styles
- `product.css` - Product page styles
- `styles.css` - General styles

### `/js/` - JavaScript Files
- `app.js` - Main application JavaScript
- `bootstrap.js` - Bootstrap configuration
- `card.js` - Card component functionality
- `cart.js` - Shopping cart functionality
- `catagary.js` - Category page interactions
- `conect_us.js` - Contact form functionality
- `product.js` - Product page interactions

### `/views/` - Blade Template Files
- Main pages: `index.blade.php`, `dashboard.blade.php`, `products.blade.php`
- Category pages: `spices.blade.php`, `ayurvedic.blade.php`, `handicraft.blade.php`
- User pages: `cart.blade.php`, `contact.blade.php`, `login.blade.php`, `create_account.blade.php`
- Components and layouts in subdirectories

## Additional Files
- `favicon.ico` - Website icon
- `robots.txt` - Search engine directives
- `package.json` - Node.js dependencies
- `vite.config.js` - Vite build configuration

## Notes
- All images and assets have been preserved with original quality
- Blade templates contain the complete UI structure
- CSS and JavaScript files maintain all functionality
- Ready for integration into a new frontend framework or static site generator
